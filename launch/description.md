**One line:** Toolweather tells agents whether an MCP server or tool is safe to call right now, and suggests working alternatives when it isn't.

**Paragraph:** Toolweather checks the top 2,000 public MCP servers every 15 minutes: handshake, auth, latency, tool list, and readiness for the 2026-07-28 spec. Agents ask one question, "is this server/tool safe to call?", and get back safe, caution, or unsafe with a reason, plus working alternatives for the same job. It also flags breaking tool changes. Free: 1,000 calls/day per key. Public status page at toolweather.pages.dev; code on GitHub.
